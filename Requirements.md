Requirements:

1. User Stories:
   - As a user, I want to be able to manage my personal accounts which include multiple bank accounts and associated transactions.
   - As a user, I would like to see the balance for each account in real-time or at any point in time I choose.
   - As a user, I would like to see a report showing my expenses classified by category for each month.
   - As a user, I would like to be able to store future bills and income and be able to see a projection of the total balance of my budget.
   - As a user, I want to keep track of expenses that relate to particular projects, e.g., a house remodeling, a trip to France.

2. Tech Stack:
   - Frontend: preferable React.js
   - Backend: preferable Node.js with Express.js or NestJs
   - Database: MongoDB, PostgreSQL, or any other relational or NoSQL database

3. API Design:
   - Create RESTful APIs for managing accounts, transactions, expenses, and budgets.
   - No authentication and authorization mechanisms are necessary for the challenge.

4. Maintainability and Quality:
   - Write clean, well-documented code.
   - Implement error handling and validation.
   - Follow best practices for database design.

5. Deployment and Scalability (Optional):
   - Provide deployment instructions for the application using Docker or any other containerization tool.
   - Explain how you would scale the application to handle a large number of users.

Deliverables:

1. Code for your challenge as a shared git repository or a zip file on email
2. Instructions to install dependencies and run the project

Evaluation Criteria:

- Problem-Solving and Critical Thinking: Your ability to identify, analyze, and provide solutions to challenges.
- Architectural Design: How well you design the web application.
- Maintainability and Quality: Clean code, proper documentation, error handling, and validation.
- Deployment and Scalability: Proper containerization, deployment instructions, and scalability considerations.
- Functionality: Demonstration of basic functionality as per user stories.
- Communication: How effectively you communicate during the pair programming session.

AI Usage:

- We incentivize the usage of AI, but come prepared to explain how and where it was used.
  - Come prepared to explain that you understand the code (whether generated by AI or not).
  - If your focus is more in one of the areas (frontend or backend), present that expectation to help us evaluate your knowledge on the code generated by AI.
